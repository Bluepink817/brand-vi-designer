# Logo System

## Analyze the supplied logo

Classify:

- symbol
- wordmark
- lettermark
- emblem
- mascot
- combination mark

Identify:

- primary silhouette
- distinctive geometry
- negative space
- rhythm
- symmetry
- memorable details

## Construction

When a construction page is requested:

- use a simple measurable unit such as X
- show only meaningful guides
- indicate proportion relationships
- avoid decorative grids that imply false mathematical precision

## Clear space

Define a repeatable clear-space unit derived from a stable logo feature.

Recommended starting point:

- at least 1X around the mark

Adjust if the mark needs more room.

## Minimum size

Set a practical minimum based on:

- print
- screen
- symbol detail
- legibility of any text

Do not invent a universal millimeter value if the actual artwork cannot support it.

## Misuse

Prohibit:

- stretching
- compressing
- arbitrary rotation
- random recoloring
- unapproved outlines
- drop shadows
- unapproved gradients
- editing type inside the logo
- low-contrast placement
- crowding within clear space

## Auxiliary graphic extraction

Priority order:

1. distinctive logo geometry
2. product form
3. brand story
4. industry symbol
5. regional/cultural element

The result should feel related to the brand even when the logo is absent.
