# Visual Direction

Translate strategy into a concrete art direction.

## Required fields

### Brand personality
3–6 adjectives.

### Visual keywords
3–6 short terms that can be judged visually.

### Color mood
Specify:

- warm / cool / neutral
- light / dark
- muted / saturated
- dominant emotional effect

### Typography mood
Specify whether the system should feel:

- geometric
- humanist
- editorial
- technical
- crafted
- refined
- bold
- understated
- playful
- formal

### Graphic language
Choose repeatable forms:

- geometry
- organic shapes
- line work
- icons
- illustration
- patterns
- frames
- modular blocks
- photographic crops

### Photography direction
Specify:

- studio / natural / documentary / lifestyle
- lighting
- camera angle
- depth of field
- background
- human presence
- product scale

### Layout direction
Specify:

- grid
- alignment
- spacing
- hierarchy
- image-to-type ratio
- asymmetry / symmetry
- density

### Material and texture
Only use materials that reinforce the brand.

Examples:

- matte paper
- uncoated stock
- brushed metal
- glass
- wood
- fabric
- recycled kraft
- glossy plastic

## Consistency test

Every proposed visual choice should answer:

1. Which brand trait does this support?
2. Does it repeat well across multiple media?
3. Can a designer reproduce the rule?
4. Does it create distinction without losing category recognition?
