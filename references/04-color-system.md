# Color System

Build a limited, usable system.

## Roles

### Primary
The most recognizable brand color.

### Secondary
Usually 2–4 supporting colors.

### Neutral
Black, white, gray, cream, or other neutral tones.

### Functional
Only when digital/product interfaces need success, warning, error, or information states.

## Specifications

For each approved brand color, provide when relevant:

- Name
- HEX
- RGB
- CMYK for print work

Pantone:
- provide only as a recommendation when a reliable match is available
- do not present an unverified match as exact

## Ratio

If useful, define an approximate usage ratio, such as:

- Primary 60%
- Secondary 25%
- Accent 10%
- Neutral 5%

Treat this as a design guide, not a rigid mathematical requirement.

## Rules

Avoid:

- too many dominant colors
- uncontrolled gradients
- poor text contrast
- different color meanings across applications

Check accessibility when the identity will be used in digital interfaces.
## Color Story Presentation

In Complete Brand Case Study mode, color should be presented as both:

1. technical specification
2. brand atmosphere

Do not only display isolated color swatches.

Show the relationship between:

- primary color
- secondary color
- accent color
- photography
- material
- application

Recommended presentation:

Brand photography
+
large brand color blocks
+
small technical specification

The viewer should understand how the brand color feels in a real environment.
