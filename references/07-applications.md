# Brand Applications

Select applications based on the brand’s real touchpoints.

## Office / stationery

Possible items:

- business card
- letterhead
- envelope
- folder
- ID badge
- notebook
- document bag
- digital signature

For presentation boards, 3–6 related objects are usually enough.

Keep:

- material family
- lighting
- background
- logo scale
- graphic language

consistent.

## Employee applications

Possible:

- T-shirt
- polo
- apron
- cap
- jacket
- workwear
- badge

Do more than place a huge logo on the chest. Consider sleeve, back, trim, label, fabric, and auxiliary graphics.

## Packaging

Possible:

- primary package
- secondary package
- label
- bag
- box
- cup
- delivery package

Typical hierarchy:

1. Brand
2. Product name
3. Core selling point
4. Variant/specification
5. Supporting information

## Advertising

Possible:

- poster
- light box
- outdoor billboard
- transit media
- store display
- digital screen
- social post
- event visual

Advertising should have a clear Key Visual, not merely a large logo.

## Social media

Build reusable templates for:

- brand
- product
- campaign
- promotion
- story/reel cover

## Mockup rule

Mockups demonstrate design; they are not the design itself.

Require:

- realistic perspective
- believable materials
- readable key information
- correct logo proportions
- restrained depth of field
- no excessive reflections
