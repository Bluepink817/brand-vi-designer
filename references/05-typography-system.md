# Typography System

Create a practical type hierarchy rather than a font collection.

## Define

- Chinese primary typeface
- Latin/English primary typeface
- optional display typeface
- numeric treatment if important
- fallback system fonts when relevant

## Hierarchy

At minimum:

- H1
- H2
- H3
- Body
- Caption

For each level, specify:

- relative size
- weight
- line height
- spacing behavior
- typical use

## Rules

Prefer no more than 2–3 main type families in one identity.

Avoid:

- random decorative fonts
- too many weights
- inconsistent tracking
- cramped line height
- body copy with poor readability
- mixing unrelated display styles

Typography should reinforce the brand personality and remain usable across print and digital media.
## Typography Case Study Presentation

Typography should be shown in two ways.

### Technical System

Show:

- Chinese font
- Latin font
- H1
- H2
- H3
- Body
- Caption

### Expressive Typography

Show how typography behaves in real brand communication.

Examples:

- campaign headline
- packaging title
- social media title
- poster headline
- slogan

Do not present typography only as a specification table.
