# Example Assets

把你拥有版权或明确授权的真实案例放在这里。

推荐结构：

```text
assets/examples/
├── coffee-brand/
│   ├── 01-industry-background.jpg
│   ├── 02-market-analysis.jpg
│   ├── 03-logo-construction.jpg
│   ├── 04-color-system.jpg
│   ├── 05-office-applications.jpg
│   └── 06-advertising-applications.jpg
├── fresh-beef-brand/
└── fashion-brand/
```

建议：

- 每个案例保持同一比例
- 优先放最终成品，不要只放 Mockup
- README 首页挑 1–2 个最强案例做预览
- 不要上传客户未授权公开的项目文件
- 不要上传字体安装包、付费模板原文件或其他无再分发授权的素材
