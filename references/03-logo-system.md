# Logo System

## Analyze the supplied logo

Classify:

- symbol
- wordmark
- lettermark
- emblem
- mascot
- combination mark

Identify:

- primary silhouette
- distinctive geometry
- negative space
- rhythm
- symmetry
- memorable details

## Construction

When a construction page is requested:

- use a simple measurable unit such as X
- show only meaningful guides
- indicate proportion relationships
- avoid decorative grids that imply false mathematical precision

## Clear space

Define a repeatable clear-space unit derived from a stable logo feature.

Recommended starting point:

- at least 1X around the mark

Adjust if the mark needs more room.

## Minimum size

Set a practical minimum based on:

- print
- screen
- symbol detail
- legibility of any text

Do not invent a universal millimeter value if the actual artwork cannot support it.

## Misuse

Prohibit:

- stretching
- compressing
- arbitrary rotation
- random recoloring
- unapproved outlines
- drop shadows
- unapproved gradients
- editing type inside the logo
- low-contrast placement
- crowding within clear space

## Auxiliary graphic extraction

Priority order:

1. distinctive logo geometry
2. product form
3. brand story
4. industry symbol
5. regional/cultural element

The result should feel related to the brand even when the logo is absent.
## Professional Construction Board Requirements

When creating a Logo Construction board, the page should clearly communicate real usage rules rather than decorative geometry.

Include the following when applicable:

### 1. Master Logo

Show the original approved logo clearly and prominently.

Do not redraw, stylize, simplify, or regenerate the logo unless the user explicitly requests a redesign.

### 2. X Unit

Derive X from a stable and recognizable part of the logo.

Use X consistently to explain:

- overall proportions
- symbol-to-wordmark spacing
- internal spacing
- clear space

Do not choose arbitrary X measurements only to make the board appear technical.

### 3. Proportion

Show meaningful relationships such as:

- total width / height
- symbol width
- wordmark width
- vertical alignment
- baseline
- spacing between symbol and type

### 4. Clear Space

Show the minimum protected area around the logo using the same X unit.

### 5. Minimum Size

Provide separate recommendations for:

- print
- screen

The minimum size must be based on actual legibility.

Do not fabricate precise dimensions when the source logo resolution is insufficient.

### 6. Incorrect Usage

Whenever space allows, include examples such as:

- stretched logo
- compressed logo
- unauthorized color
- rotation
- low contrast
- shadow
- outline
- incorrect spacing

### Accuracy Rule

Logo construction is a precision task.

When exact measurements, typography, or logo geometry are required, prefer actual vector/layout methods over generative-image approximation.

Do not rely on an image generator to invent precise construction measurements or small technical text.
## Construction Visualization Requirement

When the user requests a Logo Construction board, the board must visually demonstrate the construction rules, not only describe them in text.

Whenever the source logo allows it, show:

1. Master Logo
2. X measurement unit
3. Width and height relationships
4. Symbol-to-wordmark spacing
5. Baseline or center alignment
6. Clear-space diagram
7. Minimum-size comparison
8. Incorrect-use examples

### Diagram Requirement

At least one real construction diagram must appear on the board.

Examples:

- dimension arrows
- X-unit overlays
- alignment guides
- bounding boxes
- clear-space frames
- proportion annotations

Do not create decorative grids that do not correspond to actual logo relationships.

### Precision Rule

If the original logo source is raster-only or too low-resolution to support exact measurement:

- clearly label the construction as a recommended guideline
- do not claim mathematical precision
- do not invent exact vector geometry

If vector artwork is available, prioritize measurements derived from the actual vector artwork.

### Board Composition

A professional Logo Construction board should preferably include:

- 35–55% logo/construction diagram
- 20–30% clear-space and minimum-size examples
- 15–25% misuse examples or technical notes

The technical diagram should be visually more important than descriptive text.
