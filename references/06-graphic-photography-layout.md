# Graphic, Photography, and Layout System

## Auxiliary graphics

Use repeatable rules.

Possible systems:

- cropped logo geometry
- modular shapes
- pattern
- line system
- icon family
- illustration family
- frames
- branded containers

Do not add generic circles, waves, stars, or gradients only because the page feels empty.

## Icon system

Keep consistent:

- stroke weight
- corner radius
- perspective
- filled vs outline style
- visual size
- grid logic

## Photography

Define:

### Lighting
Natural, soft studio, hard directional, high-key, low-key, etc.

### Camera
Front, 45°, top-down, low angle, macro, wide angle.

### Background
Studio, environmental, brand color, material surface, lifestyle scene.

### Composition
Specify:

- product scale
- subject position
- negative space
- human presence
- crop behavior
- focus depth

## Layout

Use a consistent grid.

Control:

- margins
- columns
- gutters
- alignment
- baseline rhythm
- spacing units

## Hierarchy

A typical reading order:

1. Brand
2. Main message
3. Hero visual / product
4. Supporting information
5. Details

Each board should have one dominant focal point.
